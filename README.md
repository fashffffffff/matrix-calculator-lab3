# Калькулятор матриц · ЛР № 3

Библиотека и консольная демонстрация на C++17. Индивидуальный вариант № 24 — генерация случайной матрицы.

## Сборка и запуск

Понадобятся CMake 3.20+, компилятор с поддержкой C++17 и Google Test (локальная установка или доступ к GitHub для загрузки закреплённой версии).

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build --parallel
./build/matrix_calculator
ctest --test-dir build --verbose
```

Для сборки только приложения передайте `-DBUILD_TESTING=OFF` при конфигурации.

Демонстрация использует A = [[1, 2], [3, 4]] и B = [[5, 6], [7, 8]]. Выводит A + B = [[6, 8], [10, 12]], A × B = [[19, 22], [43, 50]] и случайную матрицу 3 × 4 в диапазоне [−5, 5].

## Интерфейс

| Функция | Назначение |
| --- | --- |
| `create_matrix` | Выделяет динамическую матрицу с нулевыми элементами. |
| `free_matrix` | Освобождает строки и массив указателей. |
| `matrix_from_array` | Копирует плоский массив по строкам. Вызывающий гарантирует длину буфера. |
| `matrix_add` | Складывает матрицы одинаковой размерности. |
| `matrix_multiply` | Умножает матрицы при равенстве числа столбцов A и строк B. |
| `print_matrix` | Печатает матрицу с двумя знаками после точки. Показывает начало и конец больших матриц. |
| `matrix_random` | Заполняет матрицу равномерными псевдослучайными значениями в заданном интервале. Равные границы дают константу. |

Тип `matrix::Matrix` хранит `double** data` и размеры `rows`, `cols`. Матрицы, возвращённые библиотекой, нужно один раз передать в `free_matrix`. Копирование структуры сохраняет общий указатель. После освобождения при необходимости сбросьте исходную переменную в `{}`.

Ошибки аргументов (в том числе пустые операнды, несовместимые размеры и недопустимые границы генерации) дают `std::invalid_argument`. Переполнение арифметики даёт `std::overflow_error`. Ошибка выделения памяти распространяется как `std::bad_alloc`. Пустая матрица при печати даёт `[Empty matrix]`, её освобождение безопасно. Некорректные размеры проверяются до выделения памяти.

## Сценарии тестирования

- Создание нулевой матрицы и независимое копирование массива.
- Сложение, прямоугольное умножение и произведение строки на столбец.
- Некорректные размеры, пустые операнды, отсутствующая строка и переполнение.
- Освобождение пустой матрицы, печать обычной, пустой, широкой и высокой матриц.
- Вариант № 24 с обычным, вырожденным и экстремально широким интервалами. Отдельно проверяются NaN, бесконечность, переставленные границы и нулевой размер.

## Документация, Docker и CI

```sh
doxygen Doxyfile
docker build -t matrix-calculator .
docker run --rm matrix-calculator
```

Для Doxygen требуются Doxygen и Graphviz. Главная страница создаётся в `docs/html/index.html`.

GitHub Actions выполняет сборку, CTest, Valgrind, генерацию Doxygen и проверку запуска Docker-контейнера. HTML-документация доступна как артефакт прогона.

В Linux проверку Valgrind можно повторить из корня проекта после сборки:

```sh
valgrind --leak-check=full --show-leak-kinds=all --errors-for-leak-kinds=all \
  --error-exitcode=1 ./build/tests/matrix_tests
```
